# Product Landing Page

This is a responsive Product Landing Page built as part of the [freeCodeCamp Responsive Web Design Certification](https://www.freecodecamp.org/learn/). The page showcases a product with an embedded video, a form for collecting email subscriptions, and a fixed navigation bar.

## Features

- Fixed top navigation bar with smooth section links
- Embedded product video
- Email subscription form with HTML5 validation
- Responsive design with media queries
- Flexbox layout for sections and elements

## User Stories Fulfilled

- Header with a logo image
- Navigation bar with at least 3 links
- Scrollable sections linked from the navbar
- Embedded video player
- Email subscription form with proper validation and submission link
- Always-visible navigation bar on scroll
- Mobile-friendly using media queries
- Uses CSS Flexbox for layout
